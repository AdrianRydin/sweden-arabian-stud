# Sweden Arabian Stud

## Requirements

- Node.js 20.9+
- npm
- MongoDB Atlas connection string
- Cloudinary account
- SMTP email account

## Install

npm install

## Build

npm run build

## Start

npm run start

## Environment variables

See .env.example.

## Notes

This is a full-stack Next.js app. It must be hosted with Node.js support because it uses API routes for:

- admin login/logout
- horse CRUD
- image uploads
- contact form emails
